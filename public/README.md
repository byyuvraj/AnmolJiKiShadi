# Assets Directory

Please place your background images and audio files in this directory.

Required files to replace:
- `cover.png`: The main invitation background image (needs an empty frame in the center).
- `bg-audio.mp3`: The background music for the invitation.
- `inner-bg-pattern.png`: (Optional) Background pattern for the inner page.

Files placed here will be served at the root URL (e.g., `/cover.png`).
